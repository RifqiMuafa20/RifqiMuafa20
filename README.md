# 📌 Featured Projects

## 🏋️ X-Pose Tracker

**Real-time Fitness Movement Classification & Repetition Counting**

An Android application that uses **Human Pose Estimation** and **BiLSTM** to classify and count repetitions of physical fitness test movements in real time through a smartphone camera.

### Technologies

`Kotlin` · `Android` · `CameraX` · `MediaPipe` · `LiteRT / TensorFlow Lite` · `BiLSTM` · `Room`

### Highlights

* Real-time Human Pose Estimation
* Fitness movement classification using BiLSTM
* Automatic repetition counting
* Camera-based movement analysis
* Local storage for exercise results
* Optimized for Android mobile devices

🔗 **[View Repository](https://github.com/RifqiMuafa20/X-Pose-Tracker)**

## 🛒 AIReal — E-Commerce Android Application

**Bangkit Academy Capstone Project**

AIReal is a simple Android e-commerce application developed as a **Bangkit Academy** capstone project. The application focuses on providing an e-commerce experience while implementing a **blur detection feature** to improve the quality and attractiveness of product images.

The application was developed using **Kotlin** and **XML**, with machine learning integrated into the product upload process.

### Technologies

`Kotlin` · `XML` · `Android` · `Machine Learning` · `Retrofit` · `Room / DataStore` · `Glide`

### Features

* 🔐 User Login & Registration
* 🏠 Product browsing and search
* 🔎 Product details
* 🛒 Shopping cart
* 🏪 Shop page
* 👤 User profile
* ✏️ Profile & shop editing
* 📦 Add product
* 🤖 Automatic image blur detection
* 🧾 Order history

One of the main features is **image blur detection**. When a seller uploads a product image, the application analyzes the image and detects whether it is blurry before allowing it to be used as a product image.

🔗 **[View Repository](https://github.com/Aireal-C241-PS337/mobile-android)**

## 📊 Sentiment Analysis — Running Applications

**Nike Running · Adidas Running · Strava**

A Natural Language Processing project that analyzes user reviews from three popular running applications: **Nike Running, Adidas Running, and Strava**.

The project uses **TF-IDF** for text feature representation and **Support Vector Machine (SVM)** for sentiment classification.

### Technologies

`Python` · `Pandas` · `Scikit-learn` · `NLP` · `TF-IDF` · `SVM`

### Analysis Pipeline

```text
Data Scraping
      ↓
Data Cleaning
      ↓
Text Normalization
      ↓
Tokenization
      ↓
Stopword Removal
      ↓
Stemming
      ↓
TF-IDF
      ↓
SVM Classification
      ↓
Model Evaluation
      ↓
Sentiment Analysis
```

The project demonstrates the application of **Natural Language Processing and Machine Learning** to extract insights from real-world user reviews.

🔗 **[View Repository](https://github.com/RifqiMuafa20/Sentiment-Analysis-of-Running-Apps-Using-TF-IDF-and-SVM)**
